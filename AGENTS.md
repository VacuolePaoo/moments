# Moments — Workspace Guide

Self-hosted personal "moments" (说说) site: Next.js frontend + Cloudflare Worker API, Clerk auth, D1 database, and CloudFlare ImgBed image hosting. pnpm monorepo (`apps/*`, pnpm@10.31.0).

## Layout

- `apps/api` (`@moments/api`) — Hono Worker on Cloudflare Workers. Zod 4 + `@hono/zod-openapi`, D1 binding `DB`, Clerk JWT auth, ImgBed integration. Migrations in `apps/api/migrations`.
- `apps/web` (`web`) — Next.js 16.3 App Router, React 19, Tailwind v4, shadcn/ui, Clerk. Proxies image uploads through its own server route.

## Commands (from repo root)

- `pnpm dev:api` — Worker dev server at `localhost:8787`
- `pnpm --dir apps/web dev` — Next.js at `localhost:3000`
- `pnpm check` — API pre-deploy gate: `wrangler types` + tsc + eslint + vitest + OpenAPI drift check + deploy dry-run
- `pnpm test` — API tests (vitest with the Cloudflare workers pool)
- `pnpm openapi:generate` — regenerates `openapi/openapi.json` AND `openapi/openapi.zh-CN.json` (both are checked in)
- `pnpm --filter @moments/api db:migrate:local` — apply D1 migrations to local Wrangler state
- Web only: `pnpm --dir apps/web lint` / `build` (no standalone typecheck script; `next build` type-checks)

## API architecture rules

- The OpenAPI contract is generated from the same Zod schemas (`src/schemas.ts`, `src/openapi.ts`) that validate requests at runtime. After any schema or route change, run `pnpm openapi:generate` and commit both artifacts; `pnpm openapi:check` (part of `pnpm check`) fails on drift.
- `worker-configuration.d.ts` is generated by `wrangler types` — never hand-edit it.
- D1 uses the canonical database name `moments-db` and binding `DB`; its account-specific ID is not stored in the repo. `pnpm deploy:api` creates and binds it on first deploy, then applies pending migrations. Local and remote D1 state are separate unless a command uses `--remote`.
- Secrets live in `apps/api/.dev.vars` and `apps/web/.env.local` (both gitignored; copy from the `.example` files). Production values (`ALLOWED_ORIGIN`, `CLERK_JWT_KEY`, `ADMIN_CLERK_USER_ID`, `CFBED_API_TOKEN`) are set in the Cloudflare dashboard — never in `wrangler.jsonc` (`keep_vars: true` protects them).
- Permanent delete removes ImgBed images first (batch endpoint takes at most 500 file IDs), and only deletes the D1 row after ImgBed confirms every deletion.

## Web rules

- Read `apps/web/DESIGN.md` before any UI change — it is the confirmed design spec. Key invariants: all UI copy in Simplified Chinese; feed grouped by calendar day in a fixed `Asia/Shanghai` timezone; no avatars or author identity; admin actions gated by the Worker's `isAdmin`; Lucide icons with Chinese tooltips; keep default shadcn styles/focus states; no custom animations.
- For every new or changed UI, prefer shadcn components and composition over custom primitives. First inspect `apps/web/components/ui` and `apps/web/components.json`; if the needed component is not installed, search its registry and add it with the project runner (`pnpm dlx shadcn@latest search/docs/add`) before writing UI. A missing local component is not permission to recreate it by hand. Reuse built-in variants, semantic tokens, focus states, and accessibility behavior. Write a custom component only when shadcn has no suitable primitive, and record that reason in the change summary.
- `apps/web/AGENTS.md` is auto-written by `next dev` (Next.js 16 agent rules). Next.js 16.3 may differ from training data — consult `node_modules/next/dist/docs/` before writing framework code.
- Feature components live in `apps/web/components/moments`; shadcn primitives in `components/ui`.
- Image uploads go through the web server route `POST /api/uploads` (admin-verified proxy to ImgBed). `CFBED_API_TOKEN` and `CLERK_SECRET_KEY` must never use the `NEXT_PUBLIC_` prefix.
