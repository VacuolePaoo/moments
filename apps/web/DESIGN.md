# Moments 前端设计规范

本文档记录前端设计访谈的已确认结论，作为后续实现依据。第一版不制作概念图。

## 1. 产品范围

- 公开访客与管理员使用同一站点，不拆分公开页和后台页。
- Worker 返回的 `isAdmin` 是管理界面的显示依据。
- 访客可浏览首页和日期详情页；管理员额外可以发布、编辑、删除和撤销删除。
- 不展示说说作者的头像、昵称或其他身份信息。
- 第一版不做点赞、评论、转发、浏览量、搜索、标签、RSS、草稿服务器同步和主题切换按钮。

## 2. 视觉系统

- 气质：优雅、干净、舒适，参考 shadcn 文档和 memos。
- 浅色背景使用纯白；深色主题跟随系统，不提供手动切换。
- 色彩以黑色和中性灰为主，黑色作为重点色。
- 字体使用 Inter。
- 字号采用以 `16px` 为基准、倍率 `1.125` 的 Major Second 梯度。
- 正文为 `16px`；日期 H2 约为 `25.6px`。
- 全局行高 `1.5`，不修改字间距。
- 图标统一使用 Lucide React，并为图标按钮提供中文 Tooltip 和无障碍标签。
- 优先组合 shadcn/ui 组件并保留默认样式、焦点状态和动效。
- 不增加自定义动效，日期 Hash 定位后的标题淡入高亮除外。

## 3. 页面骨架

- 页面不使用顶部导航栏和 Footer，也不显示站点标题。
- 信息流独立横向居中，沿用当前 Next.js 默认的 `max-w-3xl`（`768px`）宽度。
- 不使用侧边栏；桌面端工具胶囊悬浮于视口底部中央。
- 移动端使用同一工具胶囊，悬浮于视口顶部中央。
- 页面为悬浮工具保留安全间距，工具不改变信息流的水平居中位置。
- 移动端左右留白 `16px`。

## 4. 工具胶囊与登录

- 主胶囊依次放置“发布、日历、随机、回收站、设置”五个纯图标按钮。
- 日历、随机和设置只预留图标与 Tooltip，不实现业务功能。
- 所有图标按钮使用中文 Tooltip 和无障碍标签。
- 胶囊内按钮的 Hover 背景保持圆形。
- 主胶囊使用微妙边框与阴影；右侧留出间距放置同高的 Clerk 圆形头像区域。
- Clerk 头像占满圆形区域，不留内边距；Hover 时通过 Tooltip 显示当前用户名称。
- 发布按钮在首页聚焦发布编辑器，在其他页面返回首页；回收站仅管理员可操作。
- 未登录时点击登录，以 Clerk 模态框完成流程；成功后保留原 URL 和滚动位置。

## 5. 发布编辑器

- 仅管理员可见，位于首页信息流顶部并默认完整展开。
- 使用 shadcn `Card`、`Textarea`、`Attachment`、`Button` 等组件组合；不使用 `Field`。
- 输入框不显示占位文案，不限制长度，随内容持续增高且不设置最大高度。
- 普通 Enter 换行，`Ctrl/Cmd + Enter` 发布。
- 已选图片通过 `Attachment` 显示在输入框上方，可移除；每条说说最多 18 张图片，超出时提示并截断选择。
- 操作区位于输入框下方：左侧是图片上传图标，右侧是自动保存状态和发布按钮。
- 发布按钮带回车图标；发布时先上传新图片，取得 URL 后再创建说说。
- 发布编辑器与第一组日期之间保留 `48px`。
- 内容为空时禁止发布。
- 点击发布后显示提交状态；服务器确认成功后再将内容插入信息流并清空输入框和发布草稿。

## 6. 本地草稿

- 发布内容和每条说说的编辑内容都保存为浏览器本地草稿，不同步到服务器。
- 非管理员不读取、恢复或展示草稿；无需按 Clerk User ID 隔离。
- 停止输入 `5s` 后自动保存，成功后在发布按钮左侧显示低透明度的“已自动保存”。
- 检测到草稿后自动恢复，不显示提示。
- 删除全部文字即清除文字草稿，不提供手动保存或清除草稿按钮。
- 过期编辑草稿仍然恢复，但提示服务器原内容已发生变化。
- 取消编辑时弹出确认，让管理员选择保留或丢弃编辑草稿。
- 提交成功后清除对应草稿。

## 7. 首页信息流

- 使用无限滚动，日期从新到旧；同一天的说说也从新到旧。
- 以自然日分组，时区固定为 `Asia/Shanghai`。
- 日期格式为 `2026年8月7日 星期五`，使用 H2；标题不吸附。
- 日期标题与当天第一条内容间距 `24px`；不同日期组间距 `48px`。
- 说说平铺在滚动区域，不使用 Card，也不在日期组之间放分割线。
- 同一天有多条内容时使用细分割线，分割线上下各留 `24px`。
- 不显示单条内容的具体发布时间。
- “已编辑”标记不在首页显示，只在日期详情页显示。
- 日期标题可点击：保持普通 H2 外观，悬停时降低透明度并显示手型光标。
- 点击日期标题进入对应的日期详情页；单条正文不提供详情入口。

## 8. 正文呈现

- 纯文本按后端规范化结果展示，并保留允许的换行。
- 自动识别带 `http://` 或 `https://` 的 URL。
- 链接保留原始 URL 文本并添加下划线，悬停时降低透明度。
- 外链在新标签页打开，并设置必要的安全属性。
- 支持 emoji；长文本和长 URL 必须安全换行，不造成横向溢出。
- 图片使用 shadcn `Attachment` 组合横向展示，点击在新标签页查看原图。

## 9. 管理操作

- 管理员可在每条说说右上角通过省略号菜单执行编辑和删除。
- 桌面端省略号默认隐藏，仅在 Hover 当前说说或键盘焦点进入当前说说时显示；触屏布局保持可见。
- 编辑时正文原位置替换为 `Textarea`，下方显示“保存”和“取消”。
- 同一条内容在提交期间不得重复提交。
- 删除不弹确认框：立即软删除并从信息流移除。
- 删除后在右下角显示 `5s` Toast，提供“撤销”；使用 shadcn 默认动画。
- 撤销成功后恢复内容及原有位置。

## 10. 加载、空状态与错误

- 首次加载和加载下一页使用 2–3 行轻量 Skeleton。
- 到达列表末尾后不显示“没有更多”等提示。
- 空列表只显示简短文字“还没有内容”，不使用图标或按钮。
- 请求失败时先自动静默重试；连续失败后在信息流区域显示简短错误文字和“重试”按钮。

## 11. 回收站

- 仅管理员可管理内容，入口位于共享工具胶囊中。
- 回收站按删除时间从新到旧无限滚动，显示文字、图片和删除时间。
- 每条内容可以恢复或永久删除；永久删除前使用 `AlertDialog` 确认。
- 永久删除先删除本项目 ImgBed 中的关联图片，全部成功后再删除 Moments 数据。

## 12. 日期锚点

- 首页支持 `/#2026-08-07` 格式的日期 Hash，但不提供复制锚点入口。
- URL 包含日期 Hash 时，即使目标日期尚未加载，也要先获取相关数据并正确定位。
- 定位后，日期标题停在距视口顶部约 `32px` 的位置，并短暂淡入高亮。
- 详情页返回首页时使用带该日期 Hash 的链接。

## 13. 日期详情页

- 路由格式为 `/p/2026-08-07`，展示当天的全部说说，而非单条说说。
- 页面宽度、正文排版、同日分割规则与首页一致。
- 顶部左侧使用 H2 显示完整日期，右侧放左右翻页按钮组。
- 翻页按钮仅使用 Lucide 左右箭头，并提供 Tooltip。
- 左右翻页按相邻“有内容的日期”导航；到达边界时保留按钮并置为禁用。
- 管理员在详情页仍可对当天每条内容执行编辑和删除。
- 删除当天最后一条内容后自动返回首页并定位到原日期附近；撤销成功后恢复并回到原日期详情页。
- 日期不存在时显示简洁的“当天没有内容”和“返回”链接，不自动跳转。

## 14. 文案与元数据

- 所有项目界面、状态、错误信息、Tooltip 和 Clerk 登录界面使用简体中文。
- 首页浏览器标题为 `Moments`。
- 日期详情页标题为 `2026年8月7日 · Moments`。
- 回收站标题为 `回收站 · Moments`。

## 15. 后端契约影响

前端实现前需同步更新 Worker OpenAPI 与接口：

- 增加软删除内容的恢复接口，用于 Toast 撤销。
- 增加按 `Asia/Shanghai` 日期获取当天全部内容的接口。
- 相邻导航从“相邻单条内容”调整为“相邻有内容日期”。
- 支持首页从指定日期附近获取数据，以便直接访问日期 Hash 时完成定位。
- 单条稳定 ID 继续用于编辑、删除、恢复和外部只读 API 定位。
- 创建和修改接口接受有序图片 URL 数组，并允许只有图片的说说。
- 增加管理员回收站列表和永久删除接口；恢复继续使用原接口。
